# Локальное распознавание речи (Parakeet) — дизайн

Дата: 2026-10-08. Версия скилла после реализации: v0.4.0.

## Зачем

Скилл раздают людям, у которых нет ни своего whisperx-сервера, ни ключа облачного
провайдера. Сейчас без субтитров у видео такой человек упирается в «no ASR providers
configured». Нужен локальный движок, который:

- ставится одной командой (агент делает это сам, без sudo);
- работает на macOS (Apple Silicon) и Linux;
- сам использует GPU, если она есть, и CPU — если нет;
- понимает русский и английский;
- справляется с часовыми видео.

Он становится **вариантом по умолчанию** при настройке. Облако и whisperx остаются
опциями; конфиги, где их уже настроили, работают как раньше.

## Решение: parakeet.cpp + модель Parakeet Ultra

[mudler/parakeet.cpp](https://github.com/mudler/parakeet.cpp) (MIT) — C++/ggml-реализация
NVIDIA Parakeet. Готовые сборки в релизах GitHub: `macos-metal-arm64`, `macos-cpu-x64`,
`linux-cpu-{x64,arm64}`, `linux-vulkan-{x64,arm64}`, `linux-cuda12-x64`. Устройство
выбирается само (первая GPU из ggml), `PARAKEET_DEVICE=cpu` форсирует CPU.

Модель — [moondream/parakeet-ultra](https://huggingface.co/moondream/parakeet-ultra)
(дообученная Parakeet TDT 0.6B v3, CC-BY-4.0): 25 европейских языков, включая русский и
украинский; в веса встроена VAD-голова — `--vad` режет длинное аудио по паузам без
отдельной модели. GGUF: `mudler/parakeet-cpp-gguf`, файл `ultra-q8_0.gguf` (~0.9 ГБ).

### Проба (2026-10-08, Linux x64, Ryzen 7 5700X, RTX 5060 Ti; 35:36 русской лекции)

| сборка | время | × реального времени | RSS |
|---|---|---|---|
| CPU, 8 потоков | 100 с | ~21× | 2.2 ГБ |
| Vulkan | 12.6 с | ~170× | 1.2 ГБ |
| CUDA 12 | 11.3 с | ~190× | 1.4 ГБ |

- Покрытие полное: пауз > 8 с между словами нет, последнее слово — на последней секунде.
- Против Groq whisper-large-v3-turbo: совпадение последовательности слов 95.7%; Groq молча
  потерял три фрагмента (~106 слов), Parakeet — ни одного. CPU и GPU дают один текст (99.9%).
- Vulkan почти не уступает CUDA при 35 МБ против 890 МБ и работает на NVIDIA/AMD/Intel —
  **CUDA-сборку не используем**.
- macOS (Metal) не проверена — проверка на Mac входит в приёмку.

Отвергнутые варианты (кратко): whisper.cpp — на Linux нет установки одной командой
(apt только в Ubuntu 26.04+/Debian testing); faster-whisper — на Mac только CPU, CUDA
требует ручных библиотек и `LD_LIBRARY_PATH`; whisperx-asr-service — Docker + NVIDIA,
предлагается продвинутым отдельно (см. «Настройка»). Whisper как многоязычный запасной
локальный движок может прийти позже — поле `engine` оставлено под это.

## Что входит и что нет

Входит:
- провайдер `type: "local"` (движок `parakeet`, модель `ultra`);
- команды `local install` и `local status`;
- выбор сборки под платформу, откат GPU → CPU;
- пины версии бинарника и модели с проверкой sha256;
- предупреждение о долгой обработке (`--accept-slow`) по измеренной скорости;
- новый сценарий настройки с Parakeet по умолчанию.

Не входит: нативная Windows (WSL2 = Linux), разметка спикеров (`parakeet-cli scene`),
модели Redux/v3/1.1B, CUDA-сборка, автообновление движка, Whisper-движки.

## Конфиг

```json
{ "name": "local", "type": "local", "engine": "parakeet", "model": "ultra", "device": "auto" }
```

- `engine`: только `"parakeet"` (по умолчанию); любое другое значение — ошибка валидации.
- `model`: только `"ultra"` (по умолчанию).
- `device`: `"auto"` (по умолчанию) или `"cpu"`.
- Запрещены поля, которые для local не имеют смысла: `url`, `preset`, `tier`, `keyFile`,
  `keyEnv`, `diarize`, `local`, `maxBytes`, `maxSeconds` → ошибка с путём к полю (как
  в v0.1.1 для настроек, которые были бы проигнорированы).
- В `ResolvedProvider`: `local: true`, `keyRequired: false`, `maxBytes`/`maxSeconds`: `null`,
  `diarize: false`. Тип расширяется значением `"local"`; ветки по `type` в `select.ts`
  (доступность) и транскрипции получают третий случай.

## Где что лежит

- Бинарники: `${XDG_DATA_HOME:-~/.local/share}/video-summary/parakeet/v0.6.1/<build>/`
  (`parakeet-cli` и соседние файлы из архива).
- Модели: `${XDG_CACHE_HOME:-~/.cache}/video-summary/models/ultra-q8_0.gguf`.
- Измеренная скорость: `${XDG_STATE_HOME:-~/.local/state}/video-summary/speed.json`.
- На macOS используются те же пути (как уже сделано для `~/.config/video-summary`).

## Выбор сборки

| платформа | ставим | запускаем |
|---|---|---|
| darwin arm64 | metal-arm64 | Metal; при сбое — тот же бинарник с `PARAKEET_DEVICE=cpu` |
| darwin x64 | cpu-x64 | CPU |
| linux x64/arm64, есть `libvulkan.so.1` | vulkan **и** cpu | Vulkan; при сбое — cpu-сборка |
| linux без `libvulkan.so.1` | cpu | CPU |

- Наличие `libvulkan.so.1` проверяется по стандартным каталогам библиотек
  (`/usr/lib/x86_64-linux-gnu`, `/usr/lib/aarch64-linux-gnu`, `/usr/lib64`, `/usr/lib`) —
  без запуска `ldconfig`. Без неё Vulkan-бинарник не стартует вовсе.
- CPU-сборку на Linux ставим всегда (2–3 МБ): это гарантированный откат, если Vulkan
  есть, но драйвер не работает или GPU-устройства нет.
- `device: "cpu"` в конфиге — сразу CPU-путь.
- Если на Linux есть `nvidia-smi`, но нет `libvulkan.so.1`, `local status`/`check` дают
  подсказку: `sudo apt install libvulkan1` (needsSudo: true), после этого `local install`
  ещё раз — доставит Vulkan-сборку.

## CLI

### `local install`

1. Определяет сборки по таблице выше.
2. Для каждой отсутствующей: качает архив из релиза → проверяет размер и sha256 →
   распаковывает системным `tar -xzf` во временный каталог рядом → атомарно переименовывает
   в целевой. Битый или чужой архив удаляется, ошибка называет файл и ожидаемый хэш.
3. Модель: если файла нет или его sha256 не совпадает — качает в `.part`, проверяет размер
   и sha256, переименовывает. Прерванная загрузка оставляет только `.part`, который при
   следующем запуске перекачивается заново.
4. Идемпотентна: всё на месте и сходится — ничего не качает.
5. Печатает JSON: `{ version, builds: [...], model: { path, bytes }, downloaded_bytes }`.

Перед запуском агент называет человеку объём загрузки (~0.9 ГБ модель + 2–40 МБ
бинарники) и спрашивает согласия.

### `local status`

`{ installed, version, builds[], model: { present, verified }, vulkan_lib, hint? }` —
без сети; sha256 модели не пересчитывается каждый раз (проверяется размер; полная
проверка — только в `install`).

### `check`

Если в конфиге есть local-провайдер и движок/модель не установлены — пункт в
`deps.missing`: `{ name: "parakeet", install: "sh <skill-dir>/scripts/video-summary local install", needsSudo: false, note: "~0.9 GB download" }`.
В `providers[]` local-провайдер `available: true`, когда бинарник и модель на месте.

### `fetch … --accept-slow`

Новый флаг, см. «Предупреждение о долгой обработке».

## Распознавание (`src/local/parakeet.ts`)

1. `audio.ogg`, подготовленный тем же конвейером, что и для остальных провайдеров → ffmpeg →
   `.work/audio.wav` (16 кГц, моно, `pcm_s16le`). parakeet-cli принимает только WAV.
2. Запуск: `parakeet-cli transcribe --model <ultra> --input audio.wav --vad --json --threads <N>`,
   `N = min(availableParallelism(), 8)`. Язык не передаётся (модель определяет сама).
3. Таймаут процесса — 2 часа (у HTTP-провайдеров остаётся 30 минут). Для этого `Runner`
   получает опции `timeoutMs` и `env`; по таймауту процесс убивается (SIGTERM, через 5 с
   SIGKILL), результат — ошибка «timed out after …».
4. Откат GPU → CPU: ненулевой код GPU-запуска → один повтор на CPU (Linux: cpu-сборка,
   macOS: `PARAKEET_DEVICE=cpu`). Неудачный GPU-запуск попадает в `asr_failed` как
   `local: GPU run failed (<последняя строка stderr>), used CPU`. Падение CPU-запуска —
   обычный сбой провайдера: по правилу v0.3.1 пробуется следующий.
5. Разбор `--json`: `{ text, words: [{ w, start, end, conf }], tokens: [...] }`. Слова
   собираются в cues: новый cue начинается, если предыдущее слово кончается на `.`, `?`,
   `!` или `…`, или пауза между словами ≥ 1.0 с, или текущий cue длиннее 30 с. Пустой
   `words` при непустом аудио → ошибка «no speech recognized». Дальше — существующие
   `cleanCues` → `toParagraphs` → `transcript.md`.
6. Результат: `AsrResult { provider: <name>, diarized: false, speakers: 0, language }`,
   где `language` — язык из метаданных видео (если был), иначе `null` (parakeet-cli
   язык не сообщает).

### Языки

Список 25 языков Parakeet v3/Ultra зашит в код: bg, hr, cs, da, nl, en, et, fi, fr, de,
el, hu, it, lv, lt, mt, pl, pt, ro, sk, sl, es, sv, ru, uk. Если язык видео известен
(метаданные YouTube) и его нет в списке — local-провайдер отклоняется с причиной
`language <код> not supported`, и выбор идёт дальше (облако). Язык неизвестен
(локальный файл) — пробуем.

## Предупреждение о долгой обработке

- Оценка: `длительность / скорость`. Скорость — из `speed.json` по ключу
  `parakeet:ultra:<gpu|cpu>`, иначе консервативное значение по умолчанию: CPU 8×, GPU 60×.
- После каждого успешного локального прогона скорость обновляется:
  `новая = 0.5·старая + 0.5·измеренная` (`измеренная = длительность аудио / время
  процесса`) под ключом устройства, которое реально отработало (после отката GPU → CPU —
  `cpu`). Запись — атомарно (tmp + rename); битый файл игнорируется и перезаписывается.
- Устройство для оценки: `gpu`, если будет использована GPU-сборка (metal/vulkan) и
  `device` не `cpu`, иначе `cpu`.
- Если оценка > 10 минут и нет `--accept-slow`, local-провайдер **отклоняется** с причиной
  `~<N> min on <CPU|GPU> (measured speed <S>x); add --accept-slow to wait`. Выбор идёт
  дальше по списку; если больше никто не подходит — `UserError` со всеми причинами, агент
  спрашивает человека и при согласии повторяет с `--accept-slow`.
- Проверка — до скачивания аудио (длительность известна из метаданных; у локального
  файла — из ffprobe). При неизвестной длительности — после сжатия, по реальной.
- Только для local-провайдера. whisperx и облако не затрагиваются.

## Настройка (`references/setup.md`)

Шаг «Speech recognition» переписывается:

1. **Рекомендуется: локальное распознавание.** Агент называет объём загрузки, при
   согласии запускает `local install`, затем
   `config set providers '[{"name":"local","type":"local"}]'`. На Linux без
   `libvulkan.so.1`, но с `nvidia-smi` — подсказка про `libvulkan1` (sudo, команду
   запускает человек через `!`).
2. **Опционально — облако как запасной вариант** (Groq free и т.д.): одним вопросом;
   полезно для языков вне списка 25 и слабых CPU. Добавляется в список после local.
3. **Только если на Linux есть `nvidia-smi` и `docker`** — упомянуть
   [whisperx-asr-service](https://github.com/murtaza-nasir/whisperx-asr-service) как
   вариант с разметкой спикеров; ставит человек сам, агент только даёт ссылку.

Существующие конфиги не трогаются; в README — как добавить local в конец своего списка.

## Ошибки

Все — `UserError` одной строкой с подсказкой:
- нет бинарника/модели → «local engine not installed — run `local install`»;
- sha256/размер не сходятся → «downloaded <file> does not match the pinned checksum — retry `local install`»;
- нет сети при установке → тег сетевой ошибки (как в readeck/net);
- таймаут, пустой результат, падение CPU-запуска → через `asr_failed`/«speech recognition failed: …».

## Тестирование

Юнит-тесты с подменой `run`/`fetch`/ФС, как в остальных модулях:
- валидация конфига `local` (допустимые и запрещённые поля);
- выбор сборки: матрица платформа × arch × наличие `libvulkan.so.1` × `device`;
- `local install`: успешная установка, идемпотентность, неверный sha архива, неверный
  sha модели, прерванная загрузка (`.part`);
- запуск: команда и окружение; откат GPU → CPU (и запись в `asr_failed`); таймаут;
- разбор JSON → cues: границы по пунктуации, паузам, 30 с; пустой результат;
- языки: известный неподдерживаемый язык → следующий провайдер; неизвестный → пробуем;
- оценка времени: значения по умолчанию, обновление `speed.json`, битый файл,
  отклонение без `--accept-slow`, проход с флагом, пропуск для не-local;
- **регрессия**: существующие сценарии whisperx/groq/openai (выбор, fallback v0.3.1,
  приватность) без изменений — текущие тесты остаются зелёными без правок.

Ручная приёмка на реальных бинарниках:
- Linux x64: CPU и Vulkan, видео 30+ мин на русском, через `fetch` целиком;
- Linux без `libvulkan.so.1` (контейнер или переименованная библиотека) — ставится и
  работает cpu-сборка;
- macOS Apple Silicon (Metal) — проверяет владелец репозитория;
- английское видео; видео на неподдерживаемом языке → уход на следующий провайдер.

## Открытые вопросы на реализацию

- Ведёт ли себя Vulkan-сборка на машине без GPU-устройства как CPU или падает — откат на
  cpu-сборку покрывает оба случая, но поведение стоит зафиксировать.
- Запускается ли macOS-бинарник без дополнительной подписи (`codesign`) после загрузки
  через `fetch` (атрибут карантина не ставится, но проверить на Mac).
- Нужен ли `--min-local-conf` против «слов на шуме» — решить по ручной приёмке.
